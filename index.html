📑 전체 근무표 엑셀 파일

☁️ Supabase 클라우드 데이터베이스 연동 관리 로컬 모드 (미연동)

Supabase(클라우드 PostgreSQL)와 연동하면 근무표, 참여자 명단, 변경기록 대장이 클라우드에 자동 동기화되어 여러 PC나 담당자 간에 실시간으로 공유됩니다. 미연동 시에는 브라우저 내부 로컬 저장소(LocalStorage)에 안전하게 보관됩니다.

🔑 Supabase 연결 정보 설정

Supabase 대시보드 > Project Settings > API > Project URL
Project Settings > API > Project API keys > anon public 키

🔄 데이터 양방향 동기화 및 마이그레이션

처음 Supabase를 연결하셨다면 로컬의 기존 데이터(참여자 18인, 편성 근무표 등)를 클라우드로 한 번에 올려주세요. 다른 기기에서 작업 시에는 클라우드 데이터를 내려받아 동기화할 수 있습니다.

💡 자동 동기화 안내: Supabase가 정상 연결되어 있으면 참여자 수정, 근무표 편성/변경, 변경기록 대장 등록 시 자동으로 클라우드에 실시간 반영됩니다.

📋 Supabase 3분 세팅 가이드

  1. Supabase 프로젝트 생성: supabase.com에 로그인 후 New Project를 생성합니다.
  2. SQL 스키마 실행: 프로젝트 좌측 메뉴의 SQL Editor로 이동하여 프로젝트 루트의 supabase_schema.sql 파일 내용을 복사해 붙여넣고 [Run] 버튼을 누릅니다. (테이블 5개 및 기본 18인 자동 생성)
  3. API 키 입력: 좌측 하단 Project Settings > API에서 Project URL과 Project API keys (anon public)를 복사하여 위 입력칸에 넣고 [연결 및 저장]을 누릅니다.
